## Fenlight 0.1.3 (Early Alpha)

A launcher update with more early drops. Launchers from 0.1.2 update themselves when you open them. Co-op needs everyone on 0.1.3.

### Balance
- **More drops early in a run.** Zombies now drop loot at 5% a kill in rounds 1-5 (then the usual rate), and power-ups at 5% a kill instead of 2.5% (still at most 4 a round). A solo run should find about 3 items and 3 power-ups by the end of round 5, instead of about 1 of each.

### Fixes
- **One launcher at a time.** Opening the launcher again (or **Restart to update** in the game) brings the open launcher to the front and checks for updates, instead of starting a second copy.
- **Hosting a server:** on Windows, a server you host now stops when the launcher closes, even if it crashes or is ended from Task Manager, so it no longer keeps the port busy in the background.
- **Test and Stable:** switching from Test builds back to Stable now plays the stable version, with your stable saves, instead of the newer test build.
- The stable version stays visible even after many test builds come out.
- A download that stops receiving data now fails after 30 seconds, so **Cancel** and **Retry** work again.
- Half-finished downloads left by closing the launcher during an install are cleaned up the next time it starts.
- Clearer messages: a full disk says to check free space instead of "check your connection", and an install blocked for a moment by a virus scanner tries again.
- **Play** no longer waits for the launcher's own update check, and pressing it twice no longer starts the game twice.
- Launcher settings are saved safely, so a crash while saving no longer resets them.
