## Fenlight 0.1.2 (Early Alpha)

A launcher update. Launchers from 0.1.1 update themselves when you open them. The game itself is the same as 0.1.1, so co-op with 0.1.1 players needs everyone on 0.1.2 only because the version must match.

### New
- **Pick where to install.** The launcher no longer installs the game on its own. Press **Install**, keep the suggested folder or press **Browse…** to pick any folder or drive, see how much space it needs and how much is free, then install. Updates go to the same folder. If the game is already installed, it stays where it is.

### Fixes
- **Repair game files** now checks your files and replaces only the missing or damaged ones. It no longer deletes the game first, and no longer ends on a Retry button.
- A long message next to Game version no longer pushes the Installation panel out of the window.
- The launcher window has one fixed size.
